
# DailyMuse – AI-Powered Journaling & Habit Coach

DailyMuse is a Gen-AI-powered platform designed to help users gain mental clarity, build better habits, and reflect deeply through intelligent journaling.

It combines conversational AI, emotional awareness, and habit coaching into a single, personalized experience.

## Features

- Smart insights generated from journal entries
- Emotion-aware responses
- Habit and task suggestions
- Journal history tracking
- Conversational AI assistant ("Muse")
- AI-assisted journaling - text + audio(planned)
- Notion integration (planned)

## What It Demonstrates

- Applied Generative AI in real-world product
- Context-aware conversational systems
- Emotional intelligence in AI responses
- Full-stack AI integration (frontend + backend + APIs)


## Tech Stack

**Frontend**
- Next.js
- React
- Tailwind CSS

**Backend**
- Node.js / API routes
- Supabase (Database + Auth)

**AI Layer**
- OpenAI 


## Architecture Overview

```

User Input (Text / Audio)
↓
AI Processing Layer
(Prompt + Context + Memory)
↓
Insight Generation (Gemini)
↓
Stored in Supabase
↓
UI (Dashboard + Journal View)

````

## Use Cases

- Daily journaling with AI feedback
- Mental clarity and reflection
- Habit tracking and suggestions
- Personal growth assistant
